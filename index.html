7-day sprint

Give beginners a concrete reason to click today.

The plan is intentionally small: build a simple personal website or mini app, then improve it using Claude for planning, coding, debugging, and explanations.

Days 1–2: Learn the workflow

Set up a project, ask Claude to explain files, and create a tiny first feature.

Days 3–5: Build and debug

Use structured prompts, test changes, ask for fixes, and learn the “why” behind code.

Days 6–7: Polish and ship

Refactor, add a README, prepare a demo, and document what changed.
